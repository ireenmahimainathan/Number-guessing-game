Number Guessing Game

📝 Description

A Python-based number guessing game where the program generates a random number and the user tries to guess it. The program provides hints and keeps track of the number of attempts.

🛠️ Technologies Used

- Python 3
- Random Module
- Functions
- Loops
- Conditional Statements
- User Input
- Exception Handling

▶️ Instructions

1. Open the project in VS Code or any Python IDE.
2. Run the program using:

python number_guessing_game.py

3. Enter your guess when prompted.
4. Follow the hints provided by the program.
5. Continue guessing until you find the correct number.
